# SASD-AI-Chess
SASD Chess AI is an open-source chess engine and a machine-learning research project. Built in C++ with Python-based training, it combines fast move search, neural position evaluation, UCI interoperability, and automated self-play. The goal is a portable, extensible chess AI that learns, improves, and makes its progress measurable across platforms.

## Architecture (Deutsch)

The planned architecture is documented in [**docs/ARCHITEKTUR.md**](docs/ARCHITEKTUR.md). It describes the chess core, UCI engine and match controller, PGN import, dataset provenance, NNUE training, model validation, testing, and milestones.

> Architecture baseline only: not all described components are implemented yet.
